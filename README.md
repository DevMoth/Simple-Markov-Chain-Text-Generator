# Markov Chain Text Generator
## Description 
**MarkovChainTextGenerator** is a simple predictive text generator powered by Markov chains. 
It works by predicting what words are the most likely to follow after the user input. 
## How to use
To use the program you'll have to install a Python interpreter. 
After that simply launch the "*marcov_chain_text_generator.py*" file.
After that you will be presented with a selection of 3 modes of operation.
1. "Огурец" - is a simple meme generator, based on "дикий огурец".
2. "Ввод" - will let you input your own text for training the model.
3. "Ввод из файла" - will let you input a file name of a text file with training data.
Simply input the number of prefered mode and follow instructions.
